## 🛠️ Technology Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Custom Film Grain, Typography Tokens (Cormorant Garamond & Plus Jakarta Sans)
- **Motion & Interaction**: Framer Motion, GSAP, Lenis Smooth Scroll
- **3D Graphics**: Three.js / React Three Fiber (`HG` Monogram)
- **Icons**: Lucide React
